E-KilPay Digital Banking and Payment Platform

Project Description

E-KilPay is a fintech-based digital banking platform developed for the MIT 8103 Advanced Database Systems portfolio. The platform supports digital wallets, fund transfers, deposits, withdrawals, transaction processing, and account management.
